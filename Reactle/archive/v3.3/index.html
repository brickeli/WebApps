How to Play Reactle

Goal: Balance the chemical equation so that the number of atoms of each element is equal on both sides of the arrow.

  • Type the lowest whole number coefficients into the input boxes.
  • Leaving an input blank defaults to 1.
  • Watch the Real-time Atom Matrix updates as you type to see if reactants match products!
  • Need assistance? Click Hint to reveal steps or coefficients.
